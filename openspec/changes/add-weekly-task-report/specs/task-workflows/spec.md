# task-workflows Delta

## ADDED Requirements

### Requirement: PM-09 — Руководитель проекта — Недельный отчёт
CLI SHALL позволять руководителю получить недельный отчёт по всему выбранному проекту и при необходимости сузить его до конкретного ответственного. Отчёт SHALL содержать список закрытых за неделю, список текущих задач на контроле, количество созданных за неделю и количество текущих задач в работе, с явными периодом, timezone, областью доступа и полнотой.

#### Scenario: PM-09 — Подведение итогов недели проекта
- **WHEN** руководитель проекта: подвожу итоги недели и выбираю проект
- **THEN** участник получает четыре показателя по всем доступным задачам этого проекта без неявного ограничения текущим пользователем
- **AND** достигается рабочая цель: оценить выполненную работу, очередь приёмки и текущую нагрузку
- **AND** признак успеха: списки и количества проверяемы, период создания/закрытия отделён от текущих статусов, неполные и недоступные данные явно обозначены

#### Scenario: PM-09 — Сужение отчёта до исполнителя
- **WHEN** руководитель добавляет фильтр конкретного ответственного
- **THEN** каждый показатель относится только к задачам этого ответственного в выбранном проекте
- **AND** отсутствие фильтра сохраняет весь проект; ответственный не подменяется постановщиком задачи

#### Scenario: PM-09 — Ограниченная видимость
- **WHEN** подключение видит только часть проекта либо обход не завершён
- **THEN** отчёт показывает область доступных задач и ограничения; частичный результат не объявляется полным итогом проекта
