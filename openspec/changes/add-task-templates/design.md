# Design

## Context

Шаблоны выделены из #61 в #72. Пользователь явно отложил их реализацию. Текущие артефакты сохраняют область и трассировку, не задают готовый API-контракт.

## Goals / Non-Goals

Goal: независимая постановка будущей работы. Non-goal: любые runtime изменения шаблонов в рамках #61.

## Decisions

Оставить change активным с невыполненными задачами. При отдельном старте исследовать официальный API через MCP и заменить предварительную постановку согласованными командами/контрактами. Утверждать готовность к apply до этого нельзя.

## Risks / Trade-offs

Возможности API и полезность управления шаблонами ещё не проверены; финальная детализация scope является первой задачей #72.
