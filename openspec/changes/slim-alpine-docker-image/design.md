# Design

## Context

См. `proposal.md` для мотивации. Текущий `docker/php-cli/Dockerfile` использует `php:8.4-cli-bookworm`, Composer 2.8, installer 2.4, `unzip` и дополнительные `bcmath excimer intl pcntl opcache yaml zip`. Compose монтирует checkout и запускает `sleep infinity`; Make передаёт `LOCAL_UID/LOCAL_GID`. Dockerfile настраивает `www-data` через `groupmod/usermod`. Размер образа в этой постановке не измерялся.

В текущем lock обязательны `curl`, `intl`, `json` (SDK), `bcmath`, `filter` (moneyphp), `ctype`, `tokenizer`, `iconv` (транзитивные зависимости). `packages-dev` пуст; часть требований может уже предоставляться базовым образом. Фактически устанавливаемый набор определяется по `php -m` выбранной базы и Composer platform check, а не только по списку Dockerfile. Текущая точка входа запускает стандартные команды Symfony Console.

## Goals / Non-Goals

**Goals:** выполнить контракт `specs/docker-cli-environment/spec.md` и сохранить workflow задач #2 и #4, если они вошли в базовую `dev`.

**Non-Goals:** удаление встроенных модулей с пересборкой PHP; отдельный production runtime; изменение lock для обхода требований; новый релизный процесс.

## Decisions

1. **Официальный PHP 8.4 CLI на Alpine.** Выбрать доступный конкретный Alpine tag при реализации и записать tag/digest для сравнения. Не менять ветку PHP. Альтернатива — уменьшение Debian, но пользователь явно выбрал Alpine.
2. **Минимизировать дополнительные установки.** Сохранить `bcmath` и `intl`, обеспечить все остальные обязательные модули из lock; не переустанавливать уже встроенные. Удалить `excimer`, `pcntl`, `opcache`, `yaml`, если актуальный проект не требует их. `zip` убрать при успешной установке Composer dist-архивов через `unzip`; последний тогда имеет конкретное назначение. Не добавлять оба механизма без обоснования. Предпочесть исключение лишних RUN/COPY и очистку build-пакетов дополнительной сложности custom PHP build.
3. **Installer использовать только для нужных модулей.** Проверить совместимость существующего installer с выбранной базой; оставить его в build-стадии либо использовать временный mount, если он нужен только при сборке. Системные зависимости устанавливать средствами Alpine без пакетного кеша; библиотеки исполнения сохранить, компилятор и заголовки удалить. Альтернатива — ручная компиляция модулей, если installer не даёт корректного минимального результата.
4. **Сохранить пользовательский контракт.** Заменить Debian-специфичные операции управления пользователем совместимым с Alpine способом без установки тяжёлых вспомогательных пакетов ради `usermod`. Проверить default non-root user и Compose override на UID/GID хоста, права рабочей директории и кеша. Сохранить OCI source label, Composer и существующие Make entrypoints.
5. **Измерять сравнимые образы.** До изменения собрать baseline, затем новый образ той же архитектуры; сравнить `docker image inspect ... --format '{{.Size}}'`, записать bytes и снижение в процентах вместе с идентичностью баз. Порог в мегабайтах не назначать без измерения. Зависимости устанавливать в чистом временном checkout, не удалять пользовательский `vendor/`.

## Risks / Trade-offs

- [Переход на musl либо удаление модуля нарушает зависимости] → чистая установка lock, platform check, CLI smoke checks и актуальные линтеры; требования не игнорировать.
- [Новый lock из #4 требует дополнительные модули] → сверить lock именно базовой `dev`, обосновать каждое сохранённое расширение.
- [UID/GID либо cache отличаются на Alpine] → проверить default user, запуск с host identity и владение файлами без chmod 777.
- [Сравнение размеров разных архитектур вводит в заблуждение] → использовать одну платформу, одну метрику и записать идентичность образов.

## Migration Plan

При реализации создать отдельный worktree от актуальной `dev` по номеру issue. Изменить Dockerfile и документацию, пересобрать образ, проверить чистую установку и Make-сценарии. Передать результат через PR в `dev` с размерами и проверками; откат — revert этого изменения. Архивировать change только после реализации и проверки, затем обновить путь в issue.
