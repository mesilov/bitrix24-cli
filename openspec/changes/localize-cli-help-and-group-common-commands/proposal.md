# Proposal

## Why

Общая и командная справка b24cli смешивает русский и английский текст, а корневой help разбивает стандартные команды на два блока «Общие». Пользователю нужен единый русскоязычный обзор и одинаково понятная справка каждой команды.

## What Changes

- Перевести пользовательские заголовки, назначения, описания аргументов/опций, defaults, пояснения примеров и ограничений во всей help-поверхности на русский.
- Включить стандартные `completion`, `help`, `list` и все прикладные namespaces, включая `doctor`, `task`, `users` и `connection`; сохранить обе формы командной справки.
- Сгруппировать корневой каталог по namespace до вывода: один блок «Общие» с `completion`, `help`, `list`, затем остальные блоки, каждый ровно один раз.
- Сохранить точные CLI/API/JSON идентификаторы, значения enum, URL и машинные форматы; completion scripts остаются исполняемыми скриптами соответствующих shell.
- Актуализировать README, CLI-карту и source/offline проверки; финальная перепроверка входит в release issue #109.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `cli-experience`: добавить требования русской пользовательской справки и единого блока общих команд; существующие help/about, командная маршрутизация и offline-контракт сохраняются.

## Impact

ApplicationInformation, TaskHelpCommand/Descriptor, метаданные B24Application и прикладных команд, стандартные команды Symfony через проектный слой форматирования/регистрации, README/docs, генератор карты и help/completion тесты. Изменения ограничены представлением справки: API-вызовы, значения параметров, JSON/TSV схемы, имена команд и флагов не меняются. Добавление иных локалей и запуск релиза вне scope.
