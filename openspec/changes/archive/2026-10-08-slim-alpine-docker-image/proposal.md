# Proposal

## Why

Текущий Docker-образ перенесён из SDK: он использует Debian Bookworm и устанавливает расширения, которые текущему CLI не нужны. Нужен более компактный образ на Alpine с необходимыми зависимостями и сохранением рабочего Make/Compose окружения.

## What Changes

- Перевести сервис `php-cli` на официальный PHP 8.4 CLI образ на Alpine.
- Оставить только необходимые дополнительные PHP-расширения и системные пакеты; обосновать состав требованиями `composer.lock`, текущего приложения и инструментов проекта.
- Удалить дополнительные установки `excimer`, `pcntl`, `opcache`, `yaml`, если проверка актуальных зависимостей не выявит обязательной потребности. OPcache, уже предоставленный официальной базой, не пересобирать. `bcmath` и `intl` требуются текущим lock; необходимость `zip` оценить вместе с альтернативой `unzip` для установки Composer dist-архивов.
- Адаптировать создание непривилегированного пользователя и работу с UID/GID к Alpine, сохранив Make/Compose сценарии.
- Измерить размер старого и нового образов на одной архитектуре и подтвердить уменьшение; проверить установку зависимостей и запуск CLI.

## Capabilities

### New Capabilities

- `docker-cli-environment`: компактное Alpine окружение CLI с достаточным набором зависимостей, непривилегированным запуском и проверяемой работоспособностью.

### Modified Capabilities

Нет: актуальные спецификации отсутствуют. Совместимость с планируемой изоляцией worktree из задачи #2 сохранить.

## Impact

`docker/php-cli/Dockerfile`, `README.md`; `docker-compose.yaml` и `Makefile` — только если требуется адаптация существующих сценариев. Не менять версии PHP/SDK, прикладные команды или зависимости приложения ради уменьшения образа. Публикация production-образа, registry и релизный pipeline вне области задачи. При реализации учесть dev-инструменты задачи #4, если они уже вошли в `dev`.
