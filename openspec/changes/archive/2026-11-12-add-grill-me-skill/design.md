# Design

## Context

Upstream `grill-me` содержит только инструкцию вызвать скилл `grilling`. Без `grilling` он не работает. Оба скилла распространяются по лицензии MIT.

## Goals / Non-Goals

**Goals:** рабочий `grill-me` в репозитории, воспроизводимое происхождение.

**Non-Goals:** синхронизация с upstream, адаптация текста под проект, `grill-with-docs` и другие скиллы набора.

## Decisions

- **Вендорить копию, а не ставить через установщик.** Скиллы проекта живут в `.agents/skills/` и попадают в git. Копия на зафиксированном commit воспроизводима и не зависит от глобальной установки у разработчика. Альтернатива — глобальная установка у каждого разработчика, но она не обеспечивает одинаковое окружение.
- **Копировать `grill-me` и `grilling` целиком, включая `agents/openai.yaml`.** Без `grilling` скилл не работает, а `openai.yaml` нужен Codex для запрета неявного вызова.
- **Происхождение — в `UPSTREAM.md` и `LICENSE` в каталоге каждого скилла.** Так сведения остаются рядом с файлами при копировании.

## Risks / Trade-offs

- [Upstream меняется, копия устаревает] → Commit зафиксирован в `UPSTREAM.md`, обновление выполняется отдельным change.
