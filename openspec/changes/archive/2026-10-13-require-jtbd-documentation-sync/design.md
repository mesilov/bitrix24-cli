# Design

## Context

JTBD-документ и нижняя ссылка README уже находятся в dev после #80. Скилл мейнтейнера пока не связывает реализацию сценариев с обновлением этого документа.

## Goals / Non-Goals

Закрепить сопровождение релевантных изменений и доступную навигацию. Не распространять требование на несвязанные изменения, не менять runtime и не дублировать сами сценарии внутри скилла.

## Decisions

- Включить короткий раздел в SKILL.md со ссылкой `../../../docs/task-jtbd.md`, правилами синхронизации в том же MR и проверки перед MR/merge.
- Источники: canonical OpenSpec, фактический CommandCatalog и файлы integration tests. Сохранять IDs, источник/дату снимка и ограничения; наличие реализации/файла теста не считать сквозной live-приёмкой.
- Добавить ссылку в верхнюю навигационную строку README перед бейджами; текущую ссылку в разделе команд сохранить.
- Проверка: skill-creator quick_validate, разрешение относительных ссылок, strict OpenSpec и diff check. Для изменения инструкций отдельные runtime tests не нужны.

## Risks / Trade-offs

- Требование может затронуть несвязанный MR → явно ограничить его JTBD и связанными CLI-командами.
- «Готово» воспринимают как полное acceptance → сохранить разграничение реализации, наличия теста и полноты сценария.
