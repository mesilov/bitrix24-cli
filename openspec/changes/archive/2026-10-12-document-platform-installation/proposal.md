# Proposal

## Why

После исследования #25 пользователь выбрал подробную инструкцию установки для 0.1.0 без покупки сертификатов и попросил добавить её в README в раскрывающихся блоках в существующем PR #29. Сейчас README ссылается на build guide; подробная установка в PATH есть только для macOS, а границы первого запуска нужно показать рядом с командами.

## What Changes

- Добавить раздел установки с тремя закрытыми по умолчанию `<details>` для Linux amd64, macOS arm64 и Windows amd64.
- Описать получение archive/SHA256SUMS из одного Release/CI run, проверку checksum до распаковки, первый запуск, пользовательскую установку в PATH, проверку версии и обновление.
- Сохранить license notices и пояснить текущую проверенную OS-матрицу, предупреждения macOS/Windows и ограничения #23/SAC без обещаний исправления или платной подписи.
- Сделать README основным руководством пользователя; в build guide сохранить ссылки/якоря и требования runtime, исключив расходящиеся копии команд.

## Capabilities

### New Capabilities

Нет. Документационное изменение, `skip_specs: true`.

### Modified Capabilities

Нет. Полная `binary-distribution` прочитана; существующие требования installation/evidence исполняются без изменения поведения, сборки или политики подписи.

## Impact

README.md, раздел установки build/README.md и артефакты этого change. Продолжение в ветке PR #29, отдельный worktree; уже слитые в dev изменения #24/#27 сохранены merge. Изменения PHP, installer, CI, покупки, исправление #23 и native acceptance всех платформ в объём не входят. Прямое поручение пользователя обновить README в существующем MR разрешает подготовку и применение документации в этой работе.

Milestone существующего issue сохранён. Исследовательский change остаётся завершённым; этот change сопровождает дополнение README в [PR #29](https://github.com/mesilov/bitrix24-cli/pull/29).
