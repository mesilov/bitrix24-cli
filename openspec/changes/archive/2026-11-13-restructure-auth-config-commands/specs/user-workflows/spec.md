# Spec Delta

## MODIFIED Requirements

### Requirement: USR-04 — Сохранить рабочих адресатов профиля
CLI SHALL позволять участнику сохранить ID дефолтного наблюдателя и рабочего руководителя отдельно для каждого портала, чтобы использовать согласованных адресатов в дальнейших сценариях. Сохранение настроек SHALL не менять портал. Опциональная автодобавка наблюдателя SHALL применяться при создании задачи только при включённом профильном флаге.

#### Scenario: Keep portal-specific roles
- **WHEN** участник выполняет `config:set default.users.observerId 5 --profile work` и `config:set default.users.managerId 9 --profile work`, а clientA имеет другие рабочие роли
- **THEN** config:list --profile work показывает его default.users без смешивания адресатов разных компаний, без повторного ввода вебхука и без обращения к порталу
- **AND** признак успеха: оба ID можно проверить, отсутствие настроек не вызывает автоматический выбор человека

#### Scenario: Opt in to the default observer
- **WHEN** профиль имеет observerId=5 и autoAddObserver=true, а участник создаёт задачу
- **THEN** после создания CLI назначает ID 5 наблюдателем и показывает результат обоих шагов
- **AND** при false/отсутствующем флаге задача создаётся без автоматического назначения наблюдателя; признак успеха: настройка не вызывает неожиданных дополнительных записей
