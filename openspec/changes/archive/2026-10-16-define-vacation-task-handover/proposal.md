# Proposal

## Why

Сотрудник перед отпуском хочет одной командой передать свои незавершённые задачи проекта коллеге. Руководителю проекта нужно тем же действием перераспределять работу между двумя сотрудниками в пределах текущих прав.

## What Changes

- Добавить `task:handover --group-id ID --responsible ID [--from ID] [--max-scan N] [--dry-run]`: без `--from` источник — текущий пользователь подключения.
- Проверять активное членство обоих сотрудников в проекте и полноту выборки до записи. Передавать все доступные незавершённые задачи выбранного сотрудника в проекте, включая задачи без срока.
- Менять только `responsibleId`, проверять актуальную карточку перед назначением и ответственного после него. При первой ошибке, конфликте, отмене или неизвестном исходе прекращать следующие изменения с сохранением отчёта.
- Добавить EMP-09 и уточнить PM-04 в актуальной спецификации и основном JTBD-каталоге, обновить CLI reference, smoke, scope-manifest и Unreleased changelog.

## Capabilities

### New Capabilities

- `task-project-handover`: массовая передача задач проекта между участниками с проверками и отдельным итогом каждого назначения.

### Modified Capabilities

- `task-workflows`: EMP-09 для сотрудника и сценарий передачи между сотрудниками в PM-04.
- `task-console-runtime`: актуальный состав 49 task-команд (43 базовые + 5 шаблонов + handover).

## Impact

Новая CLI-команда, application service и gateway проверки участников проекта; повторное использование текущего bounded task scanner, REST3 TaskGateway и runtime. Добавляются документированный REST1 `sonet_group.user.get`, scope `sonet` и явный отказ strict-rest3 до API. Зависимости не меняются. Другие CLI-команды и их права сохраняются.

Команда сохраняет существующие карточки и контекст. Она не отправляет сообщения, не меняет сроки/статусы, не предоставляет новые права, не подключает HR-календарь и не возвращает задачи после отпуска. Выборка ограничена доступом подключения и фиксируется до начала записи; новые задачи во время исполнения не включаются автоматически.
