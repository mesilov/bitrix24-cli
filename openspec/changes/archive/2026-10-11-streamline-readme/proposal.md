# Proposal

## Why

README в актуальной `dev` перегружен устройством окружения, API, тестов и worktree; при этом нет компактного каталога команд и скачивания бинарников. Пользователю нужна короткая точка входа: статус проверок, загрузка нужной сборки и доступные команды.

## What Changes

- Оставить название, одно предложение о назначении CLI и три основных блока: бейджи линтеров, загрузки и команды.
- Сохранить четыре существующих бейджа Allowed licenses, PHP-CS-Fixer, PHPStan и Rector с корректными ссылками на workflows `dev`/`push`.
- Добавить загрузки последних опубликованных сборок для Linux amd64, macOS arm64 и Windows amd64; согласовать имена архивов с issue #14. До первого Release явно показать проверенные CI artifacts последней успешной матрицы с условиями их доступности.
- Перечислить все реально зарегистрированные CLI-команды с кратким назначением; сверить с `src/Bootstrap/CommandCatalog.php` и фактическим `b24cli list --raw`, включить встроенные команды и короткий пример справки.
- Удалить из README лишние подробности, длинные примеры и устаревшее утверждение, что команды задач ещё не добавлены.
- Сохранить обязательные инструкции разработки в `docs/development.md`, оставив в README одну короткую ссылку. Это сохраняет действующие требования к документации worktree и дополнительным PHP extensions.

## Capabilities

### New Capabilities

Нет: это редактура документации, без изменения поведения приложения.

### Modified Capabilities

Нет. Требования `worktree-development` и `docker-cli-environment` сохраняются; меняется только местоположение подробной документации. `.openspec.yaml` содержит `skip_specs: true` согласно схеме для изменений только документации.

- Без изменений CLI, API, зависимостей, сборочных scripts и CI workflows.
