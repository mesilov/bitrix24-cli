## MODIFIED Requirements

### Requirement: PM-04 — Руководитель проекта — Пересогласование плана
CLI SHALL позволять участнику в роли «Руководитель проекта» пересогласовать распределение работ и сроки.

#### Scenario: PM-04 — Пересогласование плана
- **WHEN** руководитель проекта: меняются приоритеты или доступность исполнителей
- **THEN** участник может пересогласовать распределение работ и сроки
- **AND** достигается рабочая цель: сохранить выполнимый план
- **AND** признак успеха: Изменения зафиксированы, затронутые участники понимают новые договорённости.

#### Scenario: PM-04 — Передача задач между сотрудниками проекта
- **WHEN** руководитель проекта перераспределяет работу между двумя сотрудниками
- **THEN** участник может явно указать исходного сотрудника и получателя и одной командой передать доступные незавершённые задачи, выбранные по исходному статусу и исключениям ID, первого в выбранном проекте второму
- **AND** оба сотрудника являются активными участниками проекта, а операции выполняются в пределах прав текущего подключения
- **AND** признак успеха: назначения подтверждены по каждой переданной задаче; ошибки и непроверенные результаты видны; сроки сохраняются, исходный статус сохраняется либо явно задаётся целевой; итог проверен

#### Scenario: PM-04 — Выборочная передача с целевым статусом
- **WHEN** руководитель выбирает исходного сотрудника, получателя, исходный статус и исключения
- **THEN** только выбранные задачи передаются; целевой статус устанавливается штатными действиями в пределах прав подключения
- **AND** назначения, переходы и непроверенные результаты видны отдельно


### Requirement: EMP-09 — Сотрудник — Передача задач коллеге перед отпуском
CLI SHALL позволять сотруднику одной командой передать выбранные доступные незавершённые задачи проекта другому активному участнику с фильтром исходного статуса, исключениями ID и необязательным целевым статусом. Назначение и итоговое состояние каждой задачи SHALL проверяться с сохранением контекста.

#### Scenario: EMP-09 — Передача задач коллеге перед отпуском
- **WHEN** сотрудник: я ухожу в отпуск и у меня остаются незавершённые задачи проекта
- **THEN** участник может одной командой передать их согласованному активному участнику этого проекта
- **AND** достигается рабочая цель: работа продолжалась без моего участия, а сроки и договорённости сохранились
- **AND** признак успеха: новый ответственный подтверждён по каждой задаче; существующие карточки и контекст сохранены; по непереданным задачам видны причины и следующие шаги

#### Scenario: EMP-09 — Передача отложенных задач с исключением
- **WHEN** сотрудник просит передать отложенные задачи Юлии ему, кроме задачи 92888, сохранив их отложенными
- **THEN** в выбранном проекте передаются только задачи исходного исполнителя в deferred за исключением 92888
- **AND** ответственный и deferred подтверждены по каждой задаче; другие задачи не меняются

#### Scenario: EMP-09 — Передача со сменой статуса
- **WHEN** сотрудник явно задаёт иной достижимый целевой статус, включая завершение либо ожидание контроля
- **THEN** выполняются штатные действия с проверками прав и результата; неполная операция не объявляется успешно завершённой
