# Spec Delta

## ADDED Requirements

### Requirement: PM-07 — Руководитель проекта — Чтение результатов задачи
CLI SHALL позволять руководителю проекта получить самостоятельные результаты выбранной задачи перед проверкой условий приёмки в пределах прав подключения.

#### Scenario: Проверка предъявленных результатов
- **WHEN** руководитель готовится проверить работу исполнителя
- **THEN** `task:result:list` показывает результаты с id, текстом, автором, датой, статусом и доступными материалами
- **AND** признак успеха: каждый результат связан с выбранной задачей и пригоден для проверки; решение о приёмке остаётся отдельным действием

### Requirement: AM-07 — Аккаунт менеджер — Получение результатов задачи
CLI SHALL позволять аккаунт менеджеру прочитать результаты выбранной задачи, чтобы подготовить передачу материалов клиенту в пределах прав подключения.

#### Scenario: Подготовка передачи клиенту
- **WHEN** команда подготовила результат по клиентскому запросу
- **THEN** менеджер получает сохранённый текст результата и доступные API сведения через `task:result:list`
- **AND** признак успеха: понятны предъявленный результат, задача и автор; отправка клиенту и его принятие фиксируются отдельным процессом

### Requirement: EMP-08 — Сотрудник — Ведение результатов задачи
CLI SHALL позволять сотруднику добавить, прочитать, исправить и удалить ошибочно созданный результат выбранной задачи в пределах прав подключения.

#### Scenario: Фиксация и исправление итога работы
- **WHEN** сотрудник завершил часть работы либо обнаружил ошибку в предъявленном результате
- **THEN** он добавляет результат, выбирает его ID из списка, изменяет текст или удаляет результат с подтверждением
- **AND** признак успеха: API подтверждает операцию над результатом этой задачи; статус задачи не меняется CLI автоматически
