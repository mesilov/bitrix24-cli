# Spec Delta

## ADDED Requirements

### Requirement: EMP-09 — Сотрудник — Передача задач коллеге перед отпуском
CLI SHALL позволять сотруднику одной командой передать все доступные незавершённые задачи выбранного проекта другому активному участнику проекта с проверкой назначения каждой задачи и сохранением существующего контекста.

#### Scenario: EMP-09 — Передача задач коллеге перед отпуском
- **WHEN** сотрудник: я ухожу в отпуск и у меня остаются незавершённые задачи проекта
- **THEN** участник может одной командой передать их согласованному активному участнику этого проекта
- **AND** достигается рабочая цель: работа продолжалась без моего участия, а сроки и договорённости сохранились
- **AND** признак успеха: новый ответственный подтверждён по каждой задаче; существующие карточки и контекст сохранены; по непереданным задачам видны причины и следующие шаги

## MODIFIED Requirements

### Requirement: PM-04 — Руководитель проекта — Пересогласование плана
CLI SHALL позволять участнику в роли «Руководитель проекта» пересогласовать распределение работ и сроки.

#### Scenario: PM-04 — Пересогласование плана
- **WHEN** руководитель проекта: меняются приоритеты или доступность исполнителей
- **THEN** участник может пересогласовать распределение работ и сроки
- **AND** достигается рабочая цель: сохранить выполнимый план
- **AND** признак успеха: Изменения зафиксированы, затронутые участники понимают новые договорённости.

#### Scenario: PM-04 — Передача задач между сотрудниками проекта
- **WHEN** руководитель проекта перераспределяет работу между двумя сотрудниками
- **THEN** участник может явно указать исходного сотрудника и получателя и одной командой передать все доступные незавершённые задачи первого в выбранном проекте второму
- **AND** оба сотрудника являются активными участниками проекта, а операции выполняются в пределах прав текущего подключения
- **AND** признак успеха: назначения подтверждены по каждой переданной задаче; ошибки и непроверенные результаты видны; сроки и статусы не меняются автоматически
