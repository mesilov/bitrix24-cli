# task-workflows Delta

## ADDED Requirements

### Requirement: PM-10 — Руководитель проекта — Ритм планёрок за период
CLI SHALL позволять руководителю получить все созвоны выбранного чата за период с датой, длительностью, инициатором и сводкой оценки участников. Оценка присутствия SHALL быть помечена как эвристика.

#### Scenario: PM-10 — Обзор планёрок за неделю
- **WHEN** руководитель проекта: хочу понять, как проходят регулярные созвоны команды, и выбираю чат и период
- **THEN** участник получает список звонков за период с длительностью, инициатором и сводкой участников
- **AND** достигается рабочая цель: заметить затянувшиеся встречи и систематические пропуски
- **AND** признак успеха: список проверяем по ID звонков, неполный обход обозначен, а оценка присутствия явно отделена от факта и не предназначена для дисциплинарных решений

### Requirement: PM-11 — Руководитель проекта — Кто сейчас на связи
CLI SHALL позволять руководителю увидеть по участникам выбранного чата или по списку пользователей время последней активности и признак отсутствия, без опоры на признаки онлайна.

#### Scenario: PM-11 — Кому написать прямо сейчас
- **WHEN** руководитель проекта: нужно быстро решить вопрос и выбираю чат команды
- **THEN** участник получает по каждому участнику время последней активности и признак отсутствия
- **AND** достигается рабочая цель: обратиться к тому, кто ответит
- **AND** признак успеха: данные проверяемы по ID пользователей, момент наблюдения указан, признак онлайна не используется
