# user-directory Delta

## ADDED Requirements

### Requirement: User presence by last activity
`users:presence` SHALL возвращать по пользователям время последней активности, признак отсутствия и момент наблюдения. Пользователей SHALL выбирать явный список ID либо участники чата из TARGET. Команда SHALL быть read-only.

#### Scenario: Участники чата
- **WHEN** пользователь передаёт TARGET чата
- **THEN** результат содержит каждого участника чата с временем последней активности, признаком отсутствия и моментом наблюдения

#### Scenario: Список ID
- **WHEN** пользователь передаёт несколько ID пользователей
- **THEN** результат содержит запись для каждого ID, а неизвестный ID отмечен отдельно и не теряется

### Requirement: Presence ignores online flags
`users:presence` SHALL не выводить выбранный статус мессенджера и признак онлайна как сведения о присутствии и SHALL объяснять в справке, почему они не используются.

#### Scenario: Признак онлайна противоречит активности
- **WHEN** портал отдаёт признак онлайна у пользователя, неактивного со вчерашнего дня
- **THEN** результат показывает только время последней активности, а признак онлайна в выводе отсутствует
