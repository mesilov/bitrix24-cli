# Proposal

## Why

По наблюдению пользователя агенты, работающие с b24cli через bitrix24-cli-skill, восполняют недостающие сценарии Bash/Python-обвязками; частота пока не измерена. Нужен воспроизводимый процесс превращения наблюдаемых траекторий в безопасные кандидаты улучшений без ручного пересказа каждого чата.

## What Changes

- Добавить переносимый формат минимальной траектории и gap report, адаптер документированного потока Codex JSONL и ручной импорт; проверить доступность истории существующих чатов, не предполагая её заранее.
- Нормализовать и обезличивать выбранные данные локально до анализа и передачи; исключать приватный текст и секреты, блокировать сомнительный экспорт.
- Анализировать пакеты 1/2/3/20/50, дедуплицировать эпизоды, различать CLI gap, skill/docs gap, обычную композицию и проблемы среды.
- Формировать проверяемые карточки сценариев с синтетическим воспроизведением, версией, знаменателем частоты и владельцем; связывать существующие issues.
- Предоставить настраиваемый периодический цикл, checkpoints и тихий режим без новых значимых результатов; по умолчанию сохранять черновики для одного пакетного triage.
- Подготовить переносимую интеграцию скилла через публичную поверхность CLI, сохранив остановку неподдерживаемой операции и запрет обходов. Автопубликация и изменение кода требуют отдельной политики/review.

## Capabilities

### New Capabilities

- `agent-trajectory-feedback`: получение наблюдаемых траекторий, минимизация данных, анализ, безопасные кандидаты и регулярный цикл улучшения.

### Modified Capabilities

Нет. Канал `user-feedback`, пока планируемый в `add-user-feedback-loop`, сохраняет требования согласия и moderation; новый процесс лишь готовит кандидатов для него.

## Impact

- Владелец процесса — bitrix24-cli; бизнес-возможности и стабильные машинные контракты относятся к CLI, правила выбора команд — к скиллу, экспорт истории — к адаптеру среды.
- Предлагаемые дополнения: автономное локальное средство анализа/сборки отчётов и публичный контракт приёма gap report. Точные CLI-имена предстоит согласовать; они не считаются уже доступными.
- Связанный репозиторий скилла: https://github.com/mesilov/bitrix24-cli-skill. Его изменение требует согласованной поставки в собственном репозитории.
- Связи: #15/#32 — feedback/publication; их сервис не блокирует локальный анализ. Основные command stdout/exit codes не меняются, portal REST-контракты здесь не изменяются.
- Сейчас только planning. Реальные чаты, сбор по расписанию, платный провайдер, автоматические исправления и merge не входят в постановку.
