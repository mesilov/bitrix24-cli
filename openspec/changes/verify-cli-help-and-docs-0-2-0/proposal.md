# Proposal

## Why

После обновления приложения до 0.2.0 справка и карта вызовов должны соответствовать фактическим публичным командам версии. Пользователю и агентскому скиллу нужны одинаковые актуальные примеры и понятная связь между документацией приложения и скиллом.

## What Changes

- Проверить общую справку `b24cli --help` и полную командную поверхность через `b24cli list`.
- Сверить справку каждой публичной команды, включая примеры, обязательные аргументы, опции, defaults и ограничения; исправить обнаруженные расхождения.
- Обновить карту CLI-вызовов в `docs/` и README по фактическому списку команд 0.2.0, сохранив ссылки на JTBD и интеграционное покрытие.
- Добавить заметную ссылку на репозиторий агентского скилла в README приложения.
- Связать отдельное issue скилла для обновления его инструкций и примеров под 0.2.0.
- Сохранить проверочный отчёт с версией, source SHA, списком команд и результатами сверки; перед закрытием проверить релизный артефакт 0.2.0.

## Capabilities

### New Capabilities

Нет: это аудит, исправление справки и обновление документации.

### Modified Capabilities

Нет: существующее требование `cli-experience / Discoverable help without remote operations` уже требует актуальные назначения, примеры, обязательные флаги, defaults, ограничения, ссылки и работу без авторизации. Change не меняет синтаксис и семантику команд; используется `skip_specs: true`.

## Impact

Затронуты `src/Console/Command/**` и bootstrap только в части справки при обнаруженных расхождениях, `README.md`, `docs/`, существующие command-map/JTBD ссылки и целевые проверки справки. Материалы скилла обновляются отдельной задачей в его репозитории. Новые API-возможности, изменение поведения команд, выпуск релиза и выполнение пользовательских операций на портале вне области этого change.
