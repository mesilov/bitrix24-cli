# Proposal

## Why

После обновления приложения до 0.2.0 справка и карта вызовов должны соответствовать фактическим публичным командам версии. Пользователю и агентскому скиллу нужны одинаковые актуальные примеры и понятная связь между документацией приложения и скиллом.

## What Changes

- Заменить вывод корневого `b24cli --help` справкой приложения: назначение b24cli, актуальный список публичных команд с краткими описаниями, глобальные опции, примеры создания, просмотра и поиска задач и способ открыть справку конкретной команды. Сейчас корневой вызов показывает справку встроенной `list`; она должна оставаться доступна через `b24cli list --help`.
- Сверять список в общей справке с фактической командной поверхностью через `b24cli list`; корневой `-h` должен давать тот же вывод, что `--help`.
- Сверить справку каждой публичной команды, включая примеры, обязательные аргументы, опции, defaults и ограничения; исправить обнаруженные расхождения.
- Обновить карту CLI-вызовов в `docs/` и README по фактическому списку команд 0.2.0, сохранив ссылки на JTBD и интеграционное покрытие.
- Добавить заметную ссылку на репозиторий агентского скилла в README приложения.
- Связать отдельное issue скилла для обновления его инструкций и примеров под 0.2.0.
- Сохранить проверочный отчёт с версией, source SHA, списком команд и результатами сверки; перед закрытием проверить релизный артефакт 0.2.0.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `cli-experience`: уточнить `Discoverable help without remote operations` — корневой `--help`/`-h` показывает обзор приложения со списком команд и примерами работы с задачами; командная справка, явный `list --help` и вызов без аргументов сохраняют собственное поведение. Для этого добавляется delta spec; `skip_specs` больше не применяется.

## Impact

Затронуты маршрутизация и форматирование help в `src/Console/` и bootstrap, `src/Console/Command/**` в части справки, `README.md`, `docs/`, существующие command-map/JTBD ссылки и целевые проверки справки. Меняется вывод корневого `--help`/`-h`; синтаксис и выполнение прикладных команд сохраняются. Материалы скилла обновляются отдельной задачей в его репозитории. Новые API-возможности, выпуск релиза и выполнение пользовательских операций на портале вне области этого change.
