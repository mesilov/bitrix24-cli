# Proposal

## Why

После обновления приложения до 0.2.0 справка и карта вызовов должны соответствовать фактическим публичным командам версии. Пользователю и агентскому скиллу нужны одинаковые актуальные примеры и понятная связь между документацией приложения и скиллом.

## What Changes

- Заменить вывод корневого `b24cli --help` справкой приложения: назначение b24cli, актуальный список публичных команд с краткими описаниями, глобальные опции, примеры создания, просмотра и поиска задач и способ открыть справку конкретной команды. Сейчас корневой вызов показывает справку встроенной `list`; она должна оставаться доступна через `b24cli list --help`.
- Сверять список в общей справке с фактической командной поверхностью через `b24cli list`; корневой `-h` должен давать тот же вывод, что `--help`.
- Добавить корневой `b24cli --about`: назначение приложения, фактическая версия сборки (как в `--version`), автор, лицензия и ссылки на репозиторий приложения и агентского скилла; вывод работает без подключения и API-запросов.
- Сверить справку каждой публичной команды, включая примеры, обязательные аргументы, опции, defaults и ограничения; исправить обнаруженные расхождения.
- Обновить карту CLI-вызовов в `docs/` и README по фактическому списку команд 0.2.0, сохранив ссылки на JTBD и интеграционное покрытие.
- Добавить заметную ссылку на репозиторий агентского скилла в README приложения.
- Связать отдельное issue скилла для обновления его инструкций и примеров под 0.2.0.
- Сохранить проверочный отчёт с версией, source SHA, списком команд и результатами source/dev сверки. По запросу пользователя повторная проверка и при необходимости актуализация на финальном артефакте 0.2.0 выполняются в отдельном релизном issue #109, change `prepare-release-0-2-0`.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `cli-experience`: уточнить `Discoverable help without remote operations` — корневой `--help`/`-h` показывает обзор приложения со списком команд и примерами работы с задачами; командная справка, явный `list --help` и вызов без аргументов сохраняют собственное поведение. Добавить требование `Application information without remote operations` для `--about`. Изменения фиксируются delta spec; `skip_specs` больше не применяется.

## Impact

Затронуты маршрутизация и форматирование help/about в `src/Console/` и bootstrap, `src/Console/Command/**` в части справки, `README.md`, `docs/`, существующие command-map/JTBD ссылки и целевые проверки справки. Меняется вывод корневого `--help`/`-h` и добавляется информационный флаг `--about`; синтаксис и выполнение прикладных команд сохраняются. Метаданные about согласуются с `BuildVersion`, LICENSE и репозиториями приложения/скилла. Материалы скилла обновляются отдельной задачей в его репозитории. Новые API-возможности, выпуск релиза и выполнение пользовательских операций на портале вне области этого change.
